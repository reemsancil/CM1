# Registered student names

Students choose their class and registered name when submitting results or looking up gifts and certificates. Edit `student-roster.js` to add students. Names and initials are copied from the supplied Lists.pdf; classes continue onto the following page.

Keep existing registered names stable: results and certificates are still associated with name plus class. Changing a registered name requires a reviewed migration of previous results and certificates. Existing records have not been deleted, renamed or automatically combined. A shortened name and a full name cannot be safely matched without the teacher confirming they belong to the same student. The teacher dashboard continues to display all existing records.

This name selection does not create student accounts or verify who is selecting a name.
